# 🐍 Snake Game – Feature Set B

A modern and attractive Snake Game developed as a college assignment project using Python. The game implements the assigned Feature Set B with score tracking, increasing speed, multiple levels, game-over detection, and high-score functionality.

---

## 🎯 Problem Statement

Develop a Snake Game with score tracking, increasing speed, multiple levels, game-over detection, and high-score functionality.

---

## 📌 Assigned Feature Set

### Problem 7 – Snake Game, Feature Set B

The assigned features are:

1. Score
2. Increasing Speed
3. Multiple Levels
4. Game-Over Detection
5. High Score

---

## ✨ Features Implemented

### 1. 🏆 Score

- The player earns points by eating food.
- The current score is displayed during gameplay.
- The score increases whenever the snake eats food.

### 2. ⚡ Increasing Speed

- The snake starts with a slow movement speed.
- Every time the snake eats food, its speed increases.
- The increasing speed makes the game progressively more challenging.
- The current speed is displayed in the game interface.

### 3. 🎮 Multiple Levels

- The game contains multiple levels/stages.
- The level increases as the player's score progresses.
- Each new level provides a greater challenge.

### 4. 💀 Game-Over Detection

- The game detects the game-over condition.
- A dedicated Game Over screen is displayed.
- The final score is shown to the player.
- The player can choose to play again or return to the home screen.

### 5. 🥇 High Score

- The game keeps track of the player's best score.
- The high score is displayed separately.
- Players can try to beat their previous high score.

### 6. ▶️ Start Game

- When the game is opened, a Start Game button is displayed.
- The game starts only after clicking the Start Game button.

### 7. 🎛️ Game Controls

The game supports:

- ⬆️ Up
- ⬅️ Left
- ⬇️ Down
- ➡️ Right
- Keyboard Arrow Keys

## ▶️ How to Play

1. Open the live game.
2. Click the **Start Game** button.
3. Control the snake using the arrow keys, WASD or the on-screen controls.
4. Move the snake towards the food.
5. Eat food to increase your score.
6. After eating food, the snake becomes faster.
7. Continue playing to progress through different levels.
8. Try to achieve the highest possible score.
9. If the game ends, click **Play Again** to start a new game.

---

## ⚡ Speed Progression

The speed system is one of the main features of Feature Set B.

- Initial speed: Slow
- Food eaten: Speed increases
- More food: Higher speed
- Higher levels: Greater challenge

This creates progressive difficulty as the game continues.
